# 🎉 Docker Shlink

Shlink is a self-hosted URL shortener that allows you to generate and manage short links, track visits with detailed analytics, and integrate with QR codes and REST APIs. It's privacy-friendly and ideal for developers and organizations.

![version](https://img.shields.io/badge/version-1.0-blue)
![rating](https://img.shields.io/badge/rating-★★★★★-yellow)
![uptime](https://img.shields.io/badge/uptime-100%25-brightgreen)

### 🔑 Generate API KEY

```
docker exec -it shlink shlink api-key:generate
```

### 🏆 Run

- [http://localhost:8000/](http://localhost:8000/) username : `admin` password : `admin`

```shell
docker-compose up -d
```
